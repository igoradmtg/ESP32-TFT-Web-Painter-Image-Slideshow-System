# ESP32-TFT-Web-Painter-Image-Slideshow-System
Этот проект представляет собой аппаратно-программный комплекс для дистанционного управления TFT-дисплеем на базе ESP32. Система объединяет возможности интерактивного рисования через веб-интерфейс и автоматического отображения потокового медиа-контента.
